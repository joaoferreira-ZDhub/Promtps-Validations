# Validation Template

## Purpose
This template is used to evaluate recorded presentations, demos, or certification submissions across multiple products and certifications.  
The evaluation must be structured, consistent, and easy to compare across submissions.

## Evaluation Mode
Detect the mode from the submission instructions or user prompt.

- **SPECIALIST mode:** Generic, market-aligned review is acceptable.
- **EXPERT mode:** Review must be strict and must explicitly align with stated customer pains or scenario needs.

## Evaluation Principles
- Use the same topic structure for every validation.
- Apply product-specific modules only when defined for the certification.
- Score each topic independently.
- Avoid double-penalizing the same issue across multiple topics unless it clearly affects different dimensions.
- Distinguish technical proof from unnecessary training/configuration detail.
- Prioritize clarity, relevance, and outcome/value articulation.

## Fixed Core Topics
Each core topic must be evaluated on a **1–5 scale** and assigned a weight impact.

| Topic | Definition | Weight Impact |
|---|---|---|
| Discovery Alignment | How well the presentation matches the stated customer need, scenario, or certification goal. | HIGH |
| Value Articulation | How clearly the presenter explains the business outcome, benefit, or impact. | HIGH |
| Product Fluency / Technical Accuracy | How accurately and credibly the presenter uses or explains the product. | HIGH |
| Scenario Coverage | How completely the presentation covers the intended use case or workflow. | MEDIUM |
| Objection Handling / Differentiation | How well the presenter addresses concerns, alternatives, or competitive differences. | MEDIUM |
| Communication Quality | Clarity, structure, pacing, confidence, and presenter presence. | MEDIUM |
| Time Management / Flow | Pacing, transitions, and overall use of time. | LOW |
| Readiness / Environment Hygiene | Screen cleanliness, realism of data, and professionalism of the environment. | LOW |

## Scoring Scale
Use the following 1–5 scoring scale for each topic:

- **1 = Poor**
- **2 = Below expectations**
- **3 = Acceptable**
- **4 = Good**
- **5 = Excellent**

## Weight Mapping
Convert weight impact into numeric multipliers:

- **LOW = 1**
- **MEDIUM = 2**
- **HIGH = 3**

## Scoring Rules
- Score every required topic.
- Multiply each topic score by its weight multiplier.
- Sum all weighted values.
- Divide by the total weight multipliers to calculate the final weighted score.
- Round the final weighted score to two decimal places.
- Use the final weighted score to determine the final grade.
- Do not double-count the same issue across multiple topics unless it affects separate dimensions.
- Penalize the most relevant topic first when the same issue appears in more than one area.

## Critical Conditions
Mark the submission as failed if any of the following occur:
- A mandatory topic is missing entirely.
- A required product/module is not demonstrated.
- The submission violates a certification-specific pass/fail rule.
- The evaluator cannot determine enough evidence to score key required topics.

## Output Requirement
The response must include:
1. A scoring table for all topics
2. Weighted score calculations
3. Final grade and verdict
4. A short feedback paragraph for the student

## Grade Bands
Assign the final grade based on the weighted score:

- **A = 4.50–5.00**
- **B+ = 4.20–4.49**
- **B = 3.80–4.19**
- **B- = 3.50–3.79**
- **C+ = 3.25–3.49**
- **C / C- = 3.00–3.24**
- **D / F = below 3.00 or failed critical condition**

## Verdict Rules
- **Approved:** A, B+, B
- **Approved (Requires Human Review):** B-, C+, C, C-
- **Fail:** D, F, or any critical condition

## Mandatory Independence Rule
Every video submission must be evaluated independently as a new validation. Prior evaluations, previous verdicts, stored conclusions, or response history must not influence the current assessment in any way.
